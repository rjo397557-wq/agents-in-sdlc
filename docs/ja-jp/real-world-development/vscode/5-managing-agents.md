GitHub Copilot を agent mode で使うと、コードベースを調べ、変更を提案し、ファイルを編集して、コマンドを実行します。VS Code の Copilot Chat では、これらの操作がローカルでリアルタイムに実行されるため、各ツールの呼び出しやファイルの編集を確認できます。差分をインラインでレビューし、個々の変更を適用または取り消し、追加のプロンプトを送って、エディターを離れずに作業を調整したり広げたりできます。

この演習では、次のことを行います。

- アクセシビリティ エージェントの作業をリアルタイムで監視します。
- 提案されたファイルの編集をレビューし、適用します。
- セッションの途中でエージェントに指示を追加し、ハイコントラストに加えてライトモードのトグルを作成します。

## シナリオ

[演習 4][previous-lesson]で使ったアクセシビリティ カスタムエージェントは、ハイコントラスト モードを実装しています。作業中、デザインチームから追加の依頼がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライトモードのトグルも追加したいとのことです。新しい会話を最初から始める代わりに、既存のセッションに指示を追加して作業の範囲を広げます。

## Copilot の進行状況を監視する

Copilot Chat ビューには、エージェントの各手順が表示されます。調べたファイル、実行したコマンド、提案された編集を確認できます。ファイルの編集は差分と **Keep** / **Undo** 操作とともに、チャット内に表示されます。

1. 演習 4 で使った Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、各ツールの呼び出しを確認します。ファイルの読み込みや編集、実行を求められたターミナル コマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がチャット内に表示されます。
    - 変更を適用するには **Keep** を選択します。
    - 変更を元に戻し、エージェントに再度作業させるには **Undo** を選択します。
4. チャットの上部にある **Files changed** の表示を開くと、このセッションでエージェントが変更したすべてのファイルを確認できます。

> [!NOTE]
> ターミナル コマンドの実行などで許可が必要な場合、エージェントは一時停止して **Allow** を表示します。実行してもよいコマンドだけを承認してください。

5. エージェントがハイコントラスト モードを実装し終えるまで待ちます。最後に、変更内容をまとめたメッセージが表示されます。

## エージェントにライトモードの追加を依頼する

ハイコントラスト モードができたら、同じ会話でライトモードのトグルも追加します。同じチャット セッションを続けるため、エージェントはこれまでの作業、変更したコンポーネント、スタイルの方針、ローカル ストレージの使い方などのコンテキストを保持しています。

1. Copilot Chat の入力欄に、次のフォローアップ プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントは既存の変更を確認し、ライトモードの追加を提案します。
3. 各編集が表示されたら、ハイコントラスト モードのときと同じようにレビューし、差分ごとに **Keep** または **Undo** を選択します。
4. エージェントが希望と異なる方針を選んだ場合（例: トグル UI を好まない方法でリファクタリングする場合）は、チャット入力欄の隣にある **Stop** ボタンで停止し、追加のメッセージで意図を説明します。

> [!TIP]
> 実行中のセッションに指示を送ると、最初からやり直すより短時間で調整できます。追加のプロンプトで変更を依頼したり（「CSS を簡潔にして、セレクターの重複ではなく CSS 変数を使う」）、方向を修正したり（「トグルを 3 つにせず、ライトモードを既存の設定パネルに組み込む」）、対象を広げたり（「両方のトグルにキーボード ショートカットも追加する」）できます。

## 作業ファイルをレビューする

作業をコミットする前に、エージェントが変更したファイルをまとめて確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストが更新されているはずです。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタムエージェントが案内したアクセシビリティのパターン（ARIA 属性、キーボード操作、セマンティック HTML、ローカル ストレージによる保存）が反映されていることを確認します。
4. 問題がなければ、**Source Control** パネルから変更をステージしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat の agent mode を使い、進行中のセッションを監視して方向付けました。ファイルの編集ごとにレビューし、変更を適用または取り消し、コンテキストを保ったままフォローアップのプロンプトを送信して作業の範囲を広げました。

この演習では、次のことを学びました。

- エージェントの作業をリアルタイムで監視する。
- 個々のファイルの編集を適用または取り消す。
- 実行中のセッションにフォローアップの指示を送る。
